# Automated-YT-channel

> An AI-powered automation pipeline for creating original children's cartoon episodes using n8n, AI, and automated media generation.

## 🚧 Project Status

**Work in Progress**

This project is being developed as an automated pipeline for producing original children's cartoon episodes with a consistent cast of characters and a completely new adventure in every episode.

The long-term goal is to automate the process from **story creation → script → audio → animation → thumbnail → YouTube publishing**.

---

## 🌟 Concept

The idea is simple:

**Keep the world and characters familiar. Make every adventure different.**

Each episode features the same core cast while introducing a completely new story, challenge, mystery, or discovery.

Episodes are designed to be approximately **8–10 minutes long** and include original children's songs or musical moments.

---

## 🎭 Main Characters

### 🍃 Lolly Leaf
A small bright-green leaf sprite with a springy stem tuft and a tiny yellow satchel with a sun badge.

**Personality:** Curious, upbeat and energetic.

### 🥁 Bop the Drum Bunny
A round cream-colored bunny wearing a sky-blue headband and carrying a tiny rainbow-strap drum.

**Personality:** Silly, rhythmic and kind.

### 🦋 Mira the Moth
A soft lavender moth with a mint scarf and gently glowing antennae.

**Personality:** Calm, wise and helpful.

The characters remain consistent across episodes while their adventures change.
